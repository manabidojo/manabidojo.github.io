～ように: so that / in order to

～ように attaches to a plain non-past verb and expresses a purpose: you do the main action so that the state in front of ように comes about. The verb before ように is typically a potential verb (聞こえる, 読める), a non-volitional verb, or a negative (忘れない).

This is the key contrast with ～ために: use ～ために when the goal is a specific, intentional action (日本へ行くために働く), and ～ように when the goal is a state, ability, result, or outcome rather than an action you can perform directly.

1. So that something becomes possible

With potential or non-volitional verbs, ～ように means you adjust your action so that the desired state happens.

みんなに聞こえるように話す。

"I speak so that everyone can hear."

  • みんな = everyone
  • に = marks the audience (to everyone)
  • 聞こえる（きこえる）= can be heard
  • ように = so that
  • 話す（はなす）= speak

2. So that something does not happen

With a ない-form verb, it means "so as not to". You act to prevent the unwanted outcome.

忘れないように、メモを書きます。

"I write a memo so that I don't forget."

  • 忘れない（わすれない）= not forget
  • ように = so that
  • メモ = memo, note
  • を = object marker
  • 書きます（かきます）= write

How to form it

Verb plain non-past (potential / non-volitional / ない-form) + ように

  • 聞こえる（きこえる）= can be heard → 聞こえるように（きこえるように）= so that it can be heard
  • 読める（よめる）= can read → 読めるように（よめるように）= so that one can read
  • 忘れる（わすれる）= to forget → 忘れないように（わすれないように）= so as not to forget

Key idea

～ように points at a desired state: you arrange your action so that the state comes about (or is avoided). If the goal is your own controllable and intentional action, ～ために is the natural choice instead.
