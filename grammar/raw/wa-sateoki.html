～はさておき: setting aside (moving to the main point)

さておく means "to set aside". ～はさておき drops one topic for now in order to move on to the main point.

In English it is "setting aside...", "... aside" or "leaving... for now". It is similar to はともかく.

Parking a topic

It sets one topic aside, such as a joke or a side question, to get to the main point.

冗談はさておき、本題に入ろう。

"Jokes aside, let's get down to business."

  • 冗談（じょうだん）= jokes
  • はさておき = setting aside
  • 本題（ほんだい）= main topic
  • に入ろう（にはいろう）= let's get into

費用の問題はさておき、まず計画を立てよう。

"Leaving aside the question of cost, let's make a plan first."

  • 費用（ひよう）= cost
  • の = (of)
  • 問題（もんだい）= question, problem
  • はさておき = setting aside
  • まず = first
  • 計画を立てよう（けいかくをたてよう）= let's make a plan

How to form it

Noun + はさておき

  • それ = that → それはさておき = that aside
  • 理由（りゆう）= reason → 理由はさておき（りゆうはさておき）= whatever the reason
  • 結果（けっか）= result → 結果はさておき（けっかはさておき）= the result aside

それはさておき alone at the start of a sentence works like "anyway" when changing the subject.

Key idea

～はさておき parks a topic so the conversation can move on to what matters now.
