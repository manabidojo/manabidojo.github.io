～こと（指示）: rule or instruction (must / must not)

こと at the end of a sentence turns it into a rule or instruction. It is used in written notices, school rules and guidelines.

In English it is like a written "must" or "(do) not...". With the ない-form, it gives a prohibition.

1. A prohibition

With the ない-form, the rule says what not to do.

廊下を走らないこと。

"No running in the hallways."

  • 廊下（ろうか）= hallway
  • を = (along)
  • 走らない（はしらない）= not run
  • こと = (rule)

2. Something that must be done

With the dictionary form, the rule says what must be done.

レポートは金曜日までに提出すること。

"Reports must be submitted by Friday."

  • レポート = report
  • は = topic marker
  • 金曜日（きんようび）= Friday
  • までに = by
  • 提出する（ていしゅつする）= to submit
  • こと = (rule)

How to form it

Verb dictionary form / ない-form + こと

  • 守る（まもる）= to keep → 時間を守ること（じかんをまもること）= be on time
  • 忘れる（わすれる）= to forget → 忘れないこと（わすれないこと）= do not forget
  • 書く（かく）= to write → 名前を書くこと（なまえをかくこと）= write your name

Key idea

～こと is the voice of a rule sheet: short, neutral and binding.
