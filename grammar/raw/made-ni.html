～までに: by (a deadline)

までに marks a deadline: the latest point by which something happens. It is different from plain まで, which means "until".

In English までに is "by" and まで is "until". The difference is whether the action happens once before the point, or continues up to it.

1. Setting a deadline

Use までに for an action that has to be completed before a point in time.

五時までに帰ってきてね。

"Be back by five, okay?"

  • 五時（ごじ）= five o'clock
  • までに = by
  • 帰ってきて（かえってきて）= come back
  • ね = okay?

2. まで versus までに

まで describes something that lasts up to a point, までに something done once before it.

三時まで待ったが、彼は来なかった。

"I waited until three, but he didn't come."

  • 三時（さんじ）= three o'clock
  • まで = until
  • 待った（まった）= waited
  • が = but
  • 来なかった（こなかった）= didn't come

How to form it

Time noun + までに, Verb dictionary form + までに

  • 明日（あした）= tomorrow → 明日までに（あしたまでに）= by tomorrow
  • 金曜日（きんようび）= Friday → 金曜日までに（きんようびまでに）= by Friday
  • 始まる（はじまる）= to start → 始まるまでに（はじまるまでに）= before it starts

Key idea

まで is a line you keep going up to, までに is a wall you have to finish before.
