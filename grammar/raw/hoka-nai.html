～ほかない／～よりほかない: have no choice but to

ほか means "other". ～ほかない literally says "there is nothing other than this", so it means there's no other option.

In English it is "have no choice but to" or "can only". It is more formal than ～しかない.

The only option left

The speaker accepts an action because there is no alternative. ～よりほかない has the same meaning with extra emphasis.

電車がないので、歩くほかない。

"There are no trains, so I have no choice but to walk."

  • 電車（でんしゃ）= train
  • が = subject marker
  • ない = there is no
  • ので = so
  • 歩く（あるく）= to walk
  • ほかない = have no choice but

自分で決めたことだから、頑張るよりほかない。

"I decided it myself, so all I can do is try my best."

  • 自分で（じぶんで）= by myself
  • 決めた（きめた）= decided
  • ことだから = since it's something
  • 頑張る（がんばる）= to try hard
  • よりほかない = nothing but

How to form it

Verb dictionary form + ほかない／よりほかない

  • 待つ（まつ）= to wait → 待つほかない（まつほかない）= can only wait
  • 諦める（あきらめる）= to give up → 諦めるほかない（あきらめるほかない）= have no choice but to give up
  • 謝る（あやまる）= to apologize → 謝るよりほかない（あやまるよりほかない）= can only apologize

～ほか仕方がない is a longer variant with the same meaning.

Key idea

～ほかない closes every other door: this is the only thing left to do.
