～さえ～ば: if only / as long as

さえ ("even") combined with the conditional ～ば says that one condition is enough for the result. Nothing else is needed.

In English it is "as long as" or "if only".

1. The only thing you need

The thing marked with さえ is the single requirement.

お金さえあれば、何でもできる。

"As long as you have money, you can do anything."

  • お金（おかね）= money
  • さえ = just, only
  • あれば = if (you) have
  • 何でも（なんでも）= anything
  • できる = can do

2. With a verb

For verbs, the pattern is ます-stem + さえすれば.

薬を飲みさえすれば、すぐ治る。

"As long as you take the medicine, you'll get better quickly."

  • 薬（くすり）= medicine
  • を = object marker
  • 飲みさえすれば（のみさえすれば）= as long as (you) take
  • すぐ = soon
  • 治る（なおる）= to heal

How to form it

Noun + さえ + ば-form, Verb ます-stem + さえすれば

  • 時間（じかん）= time → 時間さえあれば（じかんさえあれば）= if only I had time
  • 練習する（れんしゅうする）= to practice → 練習さえすれば（れんしゅうさえすれば）= as long as (you) practice
  • 天気（てんき）= weather → 天気さえよければ（てんきさえよければ）= as long as the weather is good

Key idea

～さえ～ば names one condition and says it's all you need.
