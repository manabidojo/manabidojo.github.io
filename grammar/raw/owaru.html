～終わる: finishing doing

終わる means "to end". After a verb's ます-stem, ～終わる says that an action is finished.

In English it is "finish doing". Its counterpart for starting is ～始める.

1. Finishing an action

It marks the point where the action is complete.

その本、もう読み終わった？

"Have you finished reading that book?"

  • その = that
  • 本（ほん）= book
  • もう = already
  • 読み終わった（よみおわった）= finished reading

2. What happens after finishing

Combined with ～たら, it describes what comes next once the action is done.

食べ終わったら、お皿を洗ってね。

"When you've finished eating, wash your plate."

  • 食べ終わったら（たべおわったら）= when (you've) finished eating
  • お皿（おさら）= plate
  • を = object marker
  • 洗って（あらって）= wash
  • ね = okay?

How to form it

Verb ます-stem + 終わる

  • 書く（かく）= to write → 書き終わる（かきおわる）= finish writing
  • 使う（つかう）= to use → 使い終わる（つかいおわる）= finish using
  • 話す（はなす）= to talk → 話し終わる（はなしおわる）= finish talking

～終える has the same meaning and sounds more formal: 書き終える.

Key idea

Stem + 終わる marks the end of an action, just as stem + 始める marks its start.
