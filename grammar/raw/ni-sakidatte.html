～に先立って: prior to / before

先立つ means "to go before". ～に先立って says that something is done in advance of an event, usually as preparation.

In English it is "prior to" or "ahead of". It is formal.

A step that comes first

A smaller event or some preparation takes place before the main event.

試合に先立って、開会式が行われた。

"An opening ceremony was held before the game."

  • 試合（しあい）= game
  • に先立って（にさきだって）= prior to
  • 開会式（かいかいしき）= opening ceremony
  • が = subject marker
  • 行われた（おこなわれた）= was held

新製品の発売に先立って、説明会を開く。

"We'll hold a briefing ahead of the new product's launch."

  • 新製品（しんせいひん）= new product
  • の = ('s)
  • 発売（はつばい）= release
  • に先立って（にさきだって）= ahead of
  • 説明会（せつめいかい）= briefing
  • を = object marker
  • 開く（ひらく）= to hold

How to form it

Noun / verb dictionary form + に先立って (before a noun: に先立つ + noun)

  • 公開（こうかい）= release → 公開に先立って（こうかいにさきだって）= ahead of the release
  • 出発する（しゅっぱつする）= to depart → 出発するに先立って（しゅっぱつするにさきだって）= before departing
  • 工事（こうじ）= construction → 工事に先立つ説明（こうじにさきだつせつめい）= an explanation prior to the construction

Key idea

～に先立って puts one step in front of a bigger event: first this, then the main thing.
