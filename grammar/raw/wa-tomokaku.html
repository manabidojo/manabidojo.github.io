～はともかく: setting aside / regardless of

～はともかく puts one point aside in order to focus on another that matters more.

In English it is "setting aside...", "regardless of..." or "...aside".

1. Focusing on what matters

The first point is less important, so the speaker skips it.

見た目はともかく、味はいい。

"Looks aside, it tastes good."

  • 見た目（みため）= appearance
  • はともかく = setting aside
  • 味（あじ）= taste
  • は = topic marker
  • いい = good

2. Leaving a question open

It also leaves a question unanswered for now.

結果はともかく、最後までやることが大事だ。

"Whatever the result, what matters is seeing it through."

  • 結果（けっか）= result
  • はともかく = setting aside
  • 最後まで（さいごまで）= to the end
  • やること = doing it
  • が = subject marker
  • 大事（だいじ）= important

How to form it

Noun + はともかく（として）

  • 値段（ねだん）= price → 値段はともかく（ねだんはともかく）= price aside
  • 冗談（じょうだん）= joke → 冗談はともかく（じょうだんはともかく）= joking aside
  • 勝ち負け（かちまけ）= winning or losing → 勝ち負けはともかく（かちまけはともかく）= win or lose

A question in the form ～かどうか can also be set aside: 行けるかどうかはともかく.

Key idea

～はともかく clears one point off the table so the speaker can talk about the one that matters.
