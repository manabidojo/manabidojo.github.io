～てみる: try doing something and see how it goes

～てみる is made from the て-form of a verb plus みる, which comes from 見る ("to see") but is usually written in hiragana here. The image is exactly that: you do the action to see what it is like.

It maps to English "try doing". Note the difference from ～ようとする: ～ようとする describes attempting an action (which may not happen), while ～てみる means you actually do it once and see the result.

1. Trying something out

Use ～てみる when you do something for the first time, or as an experiment, to find out how it turns out.

この服を着てみる。

"I'll try these clothes on."

  • この = this
  • 服（ふく）= clothes
  • を = object marker
  • 着てみる（きてみる）= will try on (and see)

2. Suggesting that someone try

In the form ～てみてください, it becomes a soft recommendation: "give it a try".

このケーキ、おいしいですから、食べてみてください。

"This cake is delicious, so please try it."

  • この = this
  • ケーキ = cake
  • おいしい = delicious
  • から = because / so
  • 食べてみてください（たべてみてください）= please try eating

How to form it

Verb て-form + みる

  • 着る（きる）= to wear → 着てみる（きてみる）= try on
  • 食べる（たべる）= to eat → 食べてみる（たべてみる）= try eating
  • 行く（いく）= to go → 行ってみる（いってみる）= try going

Key idea

～てみる = do it once and see. You are not sure of the result, so you do the action as a test and find out what happens.
