～や～など: things like A and B (incomplete list)

The particle や joins nouns into a list that is not complete, and など at the end makes it explicit: "and so on".

In English it is "A, B and so on" or "things like A and B". Unlike と, which lists everything, や only names some examples.

1. Listing a few examples

The items named are only examples of a larger set.

机の上に本やノートなどがある。

"There are books, notebooks and so on on the desk."

  • 机（つくえ）= desk
  • の上に（のうえに）= on top of
  • 本（ほん）= book
  • や = and (among others)
  • ノート = notebook
  • など = and so on

2. Examples of activities

It also lists things you did or like doing, without claiming the list is complete.

週末は掃除や洗濯などをした。

"On the weekend I did cleaning, laundry and so on."

  • 週末（しゅうまつ）= weekend
  • は = topic marker
  • 掃除（そうじ）= cleaning
  • や = and (among others)
  • 洗濯（せんたく）= laundry
  • など = and so on

や vs と

と lists everything: 本とノートがある means there is a book and a notebook, and nothing else. や names only some items: 本やノートがある means there are books, notebooks and other things.

How to form it

Noun + や + noun (+ や + noun) + など

  • 犬（いぬ）= dog → 犬や猫など（いぬやねこなど）= dogs, cats and so on
  • 肉（にく）= meat → 肉や魚など（にくやさかななど）= meat, fish and so on
  • 京都（きょうと）= Kyoto → 京都や奈良など（きょうとやならなど）= Kyoto, Nara and so on

など can be left out, since や alone already implies other items. It can also follow a single noun to soften a suggestion: 映画など見ませんか.

Key idea

と lists everything, や～など lists some of it. Use it when the items are only examples from a bigger set.
