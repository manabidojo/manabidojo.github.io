～としたら／～とすれば: supposing that / if

～としたら and ～とすれば set up a hypothetical assumption: "if we suppose that...".

In English it is "supposing..." or "if (it were true that)...". It is often used for imaginary or unlikely situations.

1. Imagining a situation

The speaker asks what would happen in an imagined case.

宝くじが当たったとしたら、何を買う？

"Supposing you won the lottery, what would you buy?"

  • 宝くじ（たからくじ）= lottery
  • が = subject marker
  • 当たった（あたった）= won
  • としたら = supposing
  • 何（なに）= what
  • 買う（かう）= to buy

2. Drawing a conclusion from an assumption

It also reasons from a fact: "if that's true, then...".

それが本当だとすれば、大変なことだ。

"If that's true, it's a serious matter."

  • それ = that
  • が = subject marker
  • 本当（ほんとう）= true
  • だとすれば = if (it) is
  • 大変な（たいへんな）= serious
  • ことだ = it is a matter

How to form it

Plain form + としたら／とすれば (nouns and な-adjectives take だとしたら)

  • 行く（いく）= to go → 行くとしたら（いくとしたら）= supposing (we) go
  • 無理（むり）= impossible → 無理だとすれば（むりだとすれば）= if it's impossible
  • 生まれ変わる（うまれかわる）= to be reborn → 生まれ変わるとしたら（うまれかわるとしたら）= if (I) were reborn

Key idea

～としたら builds an "if" on an assumption: suppose this is so, then what?
