～て以来: ever since

以来 (いらい) means "since then". After a て-form, ～て以来 says that a state has continued ever since a past event.

In English it is "ever since...". The second clause describes something that has been true from that point on.

A state that began with an event

The event is a clear starting point in the past, and what started then is still true now.

日本に来て以来、ずっと東京に住んでいる。

"Ever since I came to Japan, I've lived in Tokyo."

  • 日本（にほん）= Japan
  • に = to
  • 来て（きて）= came
  • 以来（いらい）= ever since
  • ずっと = the whole time
  • 東京（とうきょう）= Tokyo
  • 住んでいる（すんでいる）= live

卒業して以来、彼には一度も会っていない。

"I haven't seen him once since we graduated."

  • 卒業して（そつぎょうして）= graduated
  • 以来（いらい）= since
  • 彼（かれ）= him
  • には = (as for)
  • 一度も（いちども）= not even once
  • 会っていない（あっていない）= haven't met

How to form it

Verb て-form + 以来, Noun + 以来

  • 始める（はじめる）= to start → 始めて以来（はじめていらい）= ever since (I) started
  • 結婚する（けっこんする）= to marry → 結婚して以来（けっこんしていらい）= ever since (we) married
  • 去年（きょねん）= last year → 去年以来（きょねんいらい）= since last year

It is used for things that are still true now, not for one-time events in the near future.

Key idea

～て以来 marks a turning point in the past and says that what began then is still going on.
