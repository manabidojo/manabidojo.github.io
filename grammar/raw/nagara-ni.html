～ながらに: in a state of, while remaining as is

～ながらに attaches to a small, fixed set of nouns and verb stems and means "in the state of" or "while remaining as". English equivalents include "in tears", "by birth", and "just as it has always been". It is a literary pattern found almost only in set expressions such as 涙ながらに, 生まれながらに, and 昔ながらの.

Be careful not to confuse it with the basic ～ながら of simultaneous actions ("reading while eating"): ～ながらに does not describe two parallel actions but a state that accompanies and colors the main action.

1. Describing the state of an action: ～ながらに

Before a verb, ～ながらに works like an adverb: it tells you the condition the subject is in while doing something.

祖母は涙ながらに語った。

"My grandmother spoke in tears."

  • 祖母（そぼ）= (my) grandmother
  • は = topic marker
  • 涙（なみだ）= tears
  • ながらに = in a state of
  • 語った（かたった）= spoke, told

彼女は生まれながらに音楽の才能を持っていた。

"She had musical talent from birth."

  • 彼女（かのじょ）= she
  • は = topic marker
  • 生まれながらに（うまれながらに）= by birth, innately
  • 音楽（おんがく）= music
  • の = possessive marker
  • 才能（さいのう）= talent
  • を = object marker
  • 持っていた（もっていた）= had, possessed

2. Modifying a noun: ～ながらの

When the expression modifies a noun directly, に becomes の.

この店では昔ながらの味が楽しめる。

"At this shop you can enjoy the same taste as in the old days."

  • この = this
  • 店（みせ）= shop
  • では = at (location + topic)
  • 昔ながらの（むかしながらの）= unchanged from old times
  • 味（あじ）= taste, flavor
  • が = subject marker
  • 楽しめる（たのしめる）= can enjoy

How to form it

Noun / verb stem (limited set) + ながらに; before a noun, + ながらの

  • 涙（なみだ）= tears → 涙ながらに（なみだながらに）= in tears
  • 生まれる（うまれる）= to be born → 生まれながらに（うまれながらに）= by birth
  • 昔（むかし）= old times → 昔ながらの（むかしながらの）= just as in the old days

Key idea

～ながらに freezes a state (tears, birth, the old days) and says the action happens within that unchanged state. Learn the handful of set phrases rather than building new ones freely.
