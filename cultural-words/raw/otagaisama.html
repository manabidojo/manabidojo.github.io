お互い様 (おたがいさま)

The core idea

お互い様 means “we’re in the same position”, so there’s no need to apologize or feel indebted. People say it when someone thanks them or apologizes, meaning the favor will come back around someday, or that both sides are in the same boat.

The longer phrase 困ったときはお互い様, “when you’re in trouble, we help each other”, is said to reassure someone who’s accepting help.

In short

We all need help sometimes, so don’t worry about it.

Ways it’s used

Brushing off thanks

After helping someone.

「ありがとう」「いいよ、お互たがい様さまだから。」

“Thanks.” “Don’t mention it, you’d do the same for me.”

Accepting an apology

When both sides are in the same situation.

忙いそがしいのはお互たがい様さまです。

We’re all busy, so don’t worry about it.

Offering help

Reassuring someone.

困こまったときはお互たがい様さまですよ。

Everyone needs a hand sometimes.
